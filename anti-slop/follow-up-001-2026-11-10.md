# Tindak lanjut audit monitoring

Pengguna menyetujui temuan 3, 4, dan 5. Ketiganya telah diterapkan. Temuan 1, 2, dan 6 tidak termasuk perubahan ini.

## Perubahan

- **3, R-10:** panel dan metrik monitoring kini putih solid; kartu grafik memakai teal solid. Backdrop blur dihapus dari permukaan konten monitoring. Shell tetap memakai dua permukaan transparan sebelumnya, sidebar dan topbar. Halaman lain tidak diubah.
- **4, R-05/C-3:** urutan halaman kini judul/status, metrik, kamera beserta panel operasional, lalu riwayat sensor dan tautan dataset. Panel pembuka sebelumnya berada di bawah informasi operasional dan judulnya diperkecil menjadi 22–28 px.
- **5, R-06/C-4:** metadata menjadi 12–13 px, deskripsi panel 14 px, dan judul grafik 16 px. Aturan `.monitoring-page` menghindari perubahan ukuran di landing/login/halaman admin lain.

Alasan: putih solid memperjelas angka; metrik dan kamera lebih dahulu menjawab kebutuhan operator; teks pendukung yang lebih besar memudahkan pembacaan status dan waktu. Identitas teal tetap dipertahankan.

## Verifikasi

- `npm run typecheck`: lulus.
- Empat tes Playwright terpilih: lulus, 54,2 detik. Mencakup data grafik asli fixture, perubahan CO2/suhu, jeda pembaruan, status DEMO, snapshot, jeda kamera, layout semua route pada 320/375/768/1440 px, serta navigasi keyboard.
- Screenshot desktop dan ponsel hasil tes diperiksa visual; disimpan sebagai `docs/screenshots/monitoring-after-1440.png` dan `monitoring-after-375.png`.
- `git diff --check`: lulus.
- Tes dijalankan di salinan sementara dengan backend fixture dan server 3100, karena server pengguna di 3000 sedang memakai folder build asli. Tidak ada server pengguna yang dihentikan.

## Gate perubahan yang disetujui

- **Hard Gate, PASS dalam cakupan:** tes overflow seluruh lebar target dan kontrol monitoring terpilih lulus; tidak ada sumber data atau klaim baru ditambahkan.
- **Purpose-Gate, PASS dalam cakupan:** blur konten dihapus; alasan latar solid dan urutan informasi dicatat di atas dan di DESIGN.md.
- **Liveliness, PASS dalam cakupan:** teal, angka besar sebagai fokus, dan ritme metrik/kamera/riwayat tetap terlihat pada screenshot desktop dan ponsel. Tidak menambah animasi.
- **Craftsmanship, PASS dalam cakupan:** aplikasi dijalankan melalui tes terisolasi; empat tes dan typecheck lulus; gaya dibatasi pada monitoring.

Ini bukan sertifikasi kelulusan penuh antislop atau WCAG. Kontras seluruh pasangan warna, zoom 200%, seluruh kontrol aplikasi, dan perangkat fisik belum diuji. Temuan lain dari audit awal tetap terbuka sesuai batas persetujuan pengguna.
