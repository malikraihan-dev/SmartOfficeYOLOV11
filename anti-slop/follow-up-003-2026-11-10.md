# Empat tambahan interaksi

Dilaksanakan pada branch `feat/dashboard-login-interactions` sesuai persetujuan pengguna.

1. Strip status di atas monitoring: kamera, SCD40, audio, umur frame/pembacaan, serta umur pemeriksaan server. Umur sumber tidak disamakan dengan waktu polling. Audio tidak diberi umur buatan karena timestamp segmen belum tersedia.
2. Grafik: 12 terbaru, 1 jam, 24 jam, 7 hari. Pilihan periode mengambil maksimum 200 pembacaan terbaru dalam rentang; batas ini tertulis. Filter dijeda bersama pembaruan. Dataset sensor: tanggal awal/akhir zona browser, ringkasan dan CSV memakai filter sama. Hari akhir disertakan melalui batas eksklusif tengah malam hari berikutnya. Backend memakai parameter SQL dan menolak tanggal/periode tidak valid. Perubahan URL polling menghapus hasil rentang lama agar tidak tertukar dengan filter baru.
3. Gambar evaluasi: dialog native, tombol tutup, Escape, fokus kembali ke pemicu, tautan gambar asli dan pesan gagal muat. Tidak ada perubahan foto sumber.
4. Pengaturan deteksi/audio: penanda belum disimpan membandingkan edit dengan baseline terakhir berhasil. Kegagalan tidak membersihkan penanda; polling tetap mempertahankan edit.

## Bukti

- Typecheck dan `git diff --check` lulus.
- 7 tes dataset backend lulus, termasuk rentang dengan zona +07:00, batas akhir eksklusif, kecocokan CSV, validasi query dan pengecualian data lama dari periode.
- 8 tes autentikasi backend lulus.
- 26 tes Playwright lulus (1,8 menit), meliputi seluruh route dan layout 320/375/768/1440 px.
- Empat tes interaksi diulang setelah penyesuaian jeda grafik: lulus (17,1 detik). Dialog juga diperiksa overflow pada 375 dan 1440 px.
- Screenshot monitoring desktop/ponsel, filter tanggal, dialog gambar dan kondisi gagal simpan diperiksa visual. Screenshot monitoring/dialog disimpan di `docs/screenshots/monitoring-status-*.png` dan `image-dialog-*.png`.

## Gate dalam cakupan perubahan

- **Hard Gate PASS:** kontrol baru berfungsi dalam tes, dialog mendukung keyboard, tidak ada overflow pada lebar yang diuji, data produksi tidak direkayasa, dan tes CSV membuktikan rentang cocok.
- **Purpose-Gate PASS:** strip ringkas memudahkan pemeriksaan perangkat; filter mengurangi data yang perlu ditelusuri; dialog menjaga konteks evaluasi; penanda simpan menjelaskan edit yang belum diterapkan. Palet dan komponen yang ada digunakan kembali.
- **Liveliness PASS:** mempertahankan arahan dashboard operasional teal; ENERGY 1 / RHYTHM 1 / MOTION 1 untuk kontrol tambahan. Tidak menambah animasi atau aset dekoratif.
- **Craftsmanship PASS:** backend dan UI diuji, kondisi gagal simpan diuji, batas 200 baris dijelaskan, dan screenshot diperiksa.

Tes menggunakan backend fixture/database sementara. Perangkat fisik dan seluruh kombinasi browser belum diuji; laporan ini bukan sertifikasi WCAG penuh. Backend produksi berjalan tanpa autoreload (`debug=False`), jadi perlu restart proses Python agar filter API baru dimuat. Halaman frontend cukup direfresh setelah itu.
