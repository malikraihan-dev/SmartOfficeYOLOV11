# Audit struktur, antarmuka, dan realtime

Tanggal: 13 November 2026. Audit baca-saja terhadap kode aplikasi; screenshot diperbarui oleh tes browser.

## Cakupan dan bukti

Proyek SmartOffice_YOLOv11: Next.js App Router, React, TypeScript, CSS tokens dan Flask/SQLite. Navigasi dipetakan dengan Graphify sebelum penelusuran kode. Konvensi yang dibaca: AGENTS.md root/frontend, README root/frontend, docs/ARCHITECTURE.md, docs/DESIGN.md, dan docs/RULES.md.

Browser memakai API fixture terisolasi di port 5051 dan frontend di 3100. Fixture memakai autentikasi asli dan database sementara, bukan perangkat atau database pengguna. Penilaian visual langsung mencakup landing desktop, monitoring desktop/375px, dan dataset sensor 375px. Tes meliputi seluruh route pada 320/375/768/1440px. Ini bukan audit penuh WCAG atau validasi perangkat fisik.

| Domain | Bukti diperiksa | Hasil |
| --- | --- | --- |
| Accessibility | Tes auth, sidebar, dialog gambar, konfirmasi hapus dan navigasi keyboard | Jalur yang diuji lulus; screen reader dan audit otomatis WCAG belum diverifikasi |
| Layout | office.spec.ts:104, landing.spec.ts:20, screenshot monitoring dan dataset | Tidak ada overflow halaman pada lebar yang diuji; saran pemadatan mobile |
| Writing | Status DEMO/LIVE/KEDALUWARSA, label model, pesan kosong dan koneksi | Status jujur; saran menyederhanakan istilah teknis |
| Typography | saas.css dan screenshot desktop/mobile | Hierarki utama terbaca; label pendukung landing kecil |
| Colors | tokens.css, override saas.css, screenshot | Warna konsisten dan status disertai teks; rasio kontras hasil compositing belum diukur |
| UI | Sidebar, dialog, filter tanggal, kontrol kamera, feedback penyimpanan | Interaksi fixture lulus; FPS dan kelancaran video fisik belum diverifikasi |

Temuan arsitektur berasal dari kode. Saran visual berikut adalah peningkatan kemudahan penggunaan, bukan klaim kegagalan WCAG.

| MEDIUM | Struktur | app.py:1 | 1.092 baris menggabungkan perangkat, inference, SQL, state dan route | Pisahkan services kamera/audio, repository database, dan route bertahap | Mempermudah pengujian dan isolasi perubahan tanpa mengganti framework |
| MEDIUM | Perilaku | app.py:50, app.py:809; apps/web/src/features/settings/settings.tsx:36 | Pengaturan deteksi hanya mengubah memori dan kembali default setelah restart | Simpan konfigurasi tervalidasi ke SQLite/file konfigurasi dan muat saat startup | Pengguna tidak harus mengulang konfigurasi |

Frontend sudah tertata: app untuk route, features untuk halaman/fungsi, components untuk bagian bersama, lib untuk API/hooks/types, styles untuk tema. Backend sudah mulai dipisah melalui admin_auth.py dan sensor_dataset.py. Tidak perlu merombak seluruh proyek atau mengganti framework untuk merapikan struktur.

## Status realtime

| Fitur | Mekanisme | Kesimpulan dan batas bukti |
| --- | --- | --- |
| Status/angka monitoring | office-provider.tsx:9, polling 4.000ms | Pembaruan berkala; interval ditambah waktu request, bukan jaminan latensi 4 detik |
| Grafik sensor dan dataset/evaluasi | live-telemetry.tsx:15 dan usePoll pada fitur dataset/audio, 10.000ms | Near realtime; pengiriman sensor dan request menambah jeda |
| ESP32/SCD40 | SCD40_ESP32.ino, batas kirim minimum 5.000ms | Implementasi pengiriman ada; perangkat dan jaringan belum diuji |
| Kamera/YOLO | app.py:477, camera-panel.tsx:23, MJPEG /video_feed | Jalur streaming ada; kontrol diuji dengan fixture; FPS/inference fisik belum terukur |
| Audio | app.py:273, settings.tsx:44 | Analisis segmen 10 detik; bukan pembaruan per sampel audio; mikrofon belum diuji |
| Prediksi suhu/CO2 | models.tsx:11 | Belum terintegrasi, tidak dapat dinyatakan realtime |

use-poll.ts memakai timeout 8 detik, mencegah request tumpang tindih, membatalkan request ketika unmount, dan menjeda polling ketika tab tersembunyi. Tes stale/offline/pemulihan dan jeda grafik lulus. Belum ada pengukuran latensi end-to-end, uji beban, atau bukti sinkronisasi lintas-klien fisik.

## Verifikasi

- `python -m unittest discover -s tests -v`: 15 lulus, database sementara.
- `npm run typecheck` dari apps/web: lulus.
- `npm run test:launcher` dari root: 4 lulus.
- `npm run test:e2e` dari apps/web: 26 lulus dalam 1,6 menit, Edge headless dan API fixture.
- Tes launcher/browser awal diblokir sandbox dengan spawn EPERM; keduanya kemudian dijalankan ulang dengan izin dan lulus.
- Screenshot hasil tes diperiksa: landing-1440.png, monitoring-1440.png, monitoring-375.png, sensor-dataset-375.png.
- Belum diverifikasi: production build, screen reader, 200% text zoom, RTL, kontras komposit terukur, perangkat fisik, akurasi YOLO, latensi sensor-ke-layar dan multi-user.

## Putusan

Antarmuka: Approve terbatas pada alur fixture dan viewport yang diuji; pengukuran kontras, screen reader dan zoom masih terbuka. Tampilan cukup layak untuk prototipe lokal, dengan perbaikan bertahap pada keterbacaan dan kepadatan mobile.

Kesiapan multi-user: Block sampai kepemilikan kamera dipisah dari request. Kesiapan seluruh fitur realtime belum dapat disetujui tanpa uji perangkat, dan prediksi sensor memang belum dihubungkan.
